# Cómo proponer mejoras

Gracias por compartir experiencias y sugerencias.

## Antes de proponer
- Revisa el README y las guías vigentes para evitar duplicados.
- Explica qué problema resuelve la propuesta y a quién beneficia.
- Distingue los comportamientos de asistentes que **observaste** de los que solo esperas.
- Incluye ejemplos inventados, sin contraseñas, capturas con nombres de personas, correos ni datos de trabajo privados.
- No propongas herramientas o automatizaciones como obligatorias por defecto.
- Una recomendación para conectar servicios debe incluir permisos, riesgos, posibilidad de desconexión y revisión humana.

## Cómo colaborar
Puedes abrir una **Issue** con el problema o propuesta y enlazar la documentación correspondiente. Las propuestas no se aceptan automáticamente; sus cambios deben revisarse antes de incorporarse a la rama principal.

La difusión y selección de licencia se mantienen bajo decisión del titular. Consulta [LICENCIAMIENTO](LICENCIAMIENTO.md).

**No envíes incidentes de seguridad con datos sensibles por una Issue pública.** Consulta [SECURITY](SECURITY.md).

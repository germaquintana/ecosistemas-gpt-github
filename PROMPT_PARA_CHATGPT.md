# Prompt para solicitar una explicación esquemática a ChatGPT

**Instrucciones para tu colega:** abre [ChatGPT](https://chatgpt.com/), inicia una conversación y copia el bloque completo. No necesitas autorizar conectores para leer un repositorio público. Si ChatGPT no puede acceder a GitHub, debe indicarlo y pedirte el texto o archivos.

## Prompt listo para copiar

```text
Quiero comprender y evaluar, antes de adoptar, las buenas prácticas y configuraciones propuestas en este repositorio público:

https://github.com/germaquintana/ecosistemas-gpt-github

Actúa como asesor de gestión de proyectos, seguridad de la información y uso responsable de asistentes de IA para personas sin experiencia técnica.

1. Lee directamente el README, COMENZAR_AQUI.md, CONFIGURACIONES_Y_COMPROMISOS.md, EJEMPLO_RESPUESTA_ESQUEMATICA.md y los documentos vinculados que sean necesarios. Cita sus enlaces y distingue lo leído de lo no comprobado. No inventes características, permisos ni configuraciones.
2. Devuélveme una RESPUESTA ESQUEMÁTICA EN ESPAÑOL con:
   A. Un mapa sencillo del ecosistema Persona → IA → GitHub → Fuentes → Verificación, y qué herramienta hace qué.
   B. Tabla de 7 buenas prácticas: qué significan, qué tendría que configurar y para qué sirven.
   C. Tres niveles: BASE RECOMENDADA, OPCIONAL y REQUIERE AUTORIZACIÓN EXPRESA.
   D. Qué NO sucede por abrir el enlace: no se instala nada, no se conectan apps, no se modifican mis cuentas, no se comparten mis datos.
   E. Riesgos y límites: datos personales, documentos institucionales, permisos, instrucciones maliciosas, errores de IA y acciones irreversibles.
   F. Una ruta de implementación en 5 pasos con una primera tarea pequeña y verificable.
   G. Una checklist final para decidir qué prácticas acepto y cuáles pospongo.
3. Habla en términos claros y utiliza un diagrama Mermaid si tu interfaz lo admite. No asumas que trabajo en una municipalidad ni que tengo GitHub configurado.
4. Pregúntame AL FINAL únicamente qué tipo de proyecto quiero organizar y qué herramientas utilizo actualmente. Primero entrégame el esquema completo, sin esperar mi respuesta.
5. NO ejecutes cambios, no crees repositorios, no solicites contraseñas ni conectes cuentas. Cualquier cambio posterior requiere mi solicitud y autorización específicas.

Si el repositorio contiene contradicciones o no está disponible, adviértelo con precisión. La guía es una recomendación educativa, no una política institucional obligatoria ni una suscripción automática.
```

## ¿Qué deberías recibir?

Revisa [este ejemplo orientador](EJEMPLO_RESPUESTA_ESQUEMATICA.md). Compara tu respuesta con la fuente y recuerda que **ningún prompt transforma recomendaciones en permisos de acceso**.

Si más adelante quieres que el asistente implemente tu sistema, haz una solicitud separada, comprueba sus herramientas y revisa los permisos antes de autorizar.

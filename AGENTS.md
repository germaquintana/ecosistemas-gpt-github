# AGENTS — convivencia de chats y seguridad pública (16-11-2026)

**Función:** Repositorio público de guías y buenas prácticas para colegas; los ejemplos deben ser reutilizables y no contener configuración privada.

Adoptar la [guía pública de convivencia de ejecutores](https://github.com/germaquintana/ecosistemas-gpt-github/blob/main/GUIA_CONVIVENCIA_CHATS_Y_EJECUTORES_V1.md). Una reserva/lock activo de otro chat no es automáticamente un error: omitir ese recurso y buscar trabajo alternativo independiente **en el mismo ciclo**, sin liberar locks ajenos ni adivinar si un chat terminó. Si no existe lock propio, operar con SHA/versiones y sin afirmar exclusión mutua.

No trasladar datos C2/C3, fuentes internas, credenciales, nombres ni expedientes privados a este repo público. Una mención a una automatización, cola o proyecto no autoriza publicación, cambios de permisos ni despliegues. Los enlaces web deben probarse por separado del commit. Todo RUN debe indicar fuentes, SHA, producto, QA y próximo paso sin inventar evidencia.

# Situación de licenciamiento

**Pendiente de decisión del titular del repositorio.** La visibilidad pública de GitHub permite leer el contenido, pero no equivale por sí misma a una licencia abierta para su reutilización, modificación o redistribución.

Esta biblioteca fue preparada para facilitar el aprendizaje y la creación de proyectos propios. Antes de anunciar una licencia específica, el titular debe decidir los términos aplicables a documentación, ejemplos y eventual código.

Opciones a evaluar: **CC BY 4.0** para documentación original y **MIT** para código de ejemplo, considerando autoría, atribuciones y materiales de terceros. No se afirma que esas licencias estén hoy adoptadas.

Para reutilizaciones más allá de lo permitido por ley, solicita autorización del titular mientras no exista un archivo de licencia aplicable.

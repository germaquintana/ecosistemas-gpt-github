# 08 · Cómo compartir y mantener esta biblioteca pública

Esta biblioteca es material educativo genérico. La gestión privada de proyectos, participantes o instituciones debe permanecer en repositorios separados y con acceso autorizado.

## Antes de publicar
1. Revisar cada archivo y su **historial** por datos personales, credenciales, links con permisos, expedientes y material protegido por derechos de autor.
2. Usar ejemplos ficticios; no exportar automáticamente desde repositorios privados.
3. Comprobar enlaces internos y que el prompt de entrada describe solo el estado realmente disponible.
4. Confirmar visibilidad y licencia escogida por el titular antes de anunciar derechos de reutilización amplios.
5. Verificar desde una sesión pública que el README y las guías sean accesibles.

## Mantenimiento
Proponer mejoras en Issues públicas sin compartir datos reservados. Para cambios de seguridad, tratar primero por un canal privado acordado; no adjuntar tokens.

Las nuevas guías deben diferenciar requisitos universales (como no exponer datos y actuar con autorización), recomendaciones configurables y herramientas opcionales. Documentar versiones y no crear obligaciones inexistentes.

# 07 · Ejemplo completo ficticio: organizar una actividad

**Proyecto:** organizar una sesión de aprendizaje de herramientas digitales. Todas las personas y datos de este ejercicio son ficticios.

### Definición
- Objetivo: preparar material claro para una actividad de dos horas.
- Entregable: agenda, guía y lista de verificación revisadas.
- Responsable: persona organizadora ficticia.
- Plazo: fecha interna decidida por la persona, no fecha legal.
- Criterio de aceptación: archivos legibles, fuentes correctas y revisión humana.

### Esquema de carpetas
```text
mi-proyecto/
  README.md
  AGENTS.md
  PROYECTO.md
  estado_proyecto.json
  bitacora/
    RUN-EJEMPLO.md
```

### Primer ciclo
1. Leer objetivo y estado.
2. Preparar un índice de tres secciones.
3. Comprobar que responda al objetivo y no contenga datos reales.
4. Registrar que el índice se creó y quién debe aprobarlo.
5. Dejar la próxima acción: redactar la primera sección.

### Cierre
Una guía generada no equivale a material entregado. Documenta cuándo y quién revisó y cuándo se compartió, si ello sucede realmente.

Puedes copiar una estructura para comenzar desde [plantilla-proyecto](../plantilla-proyecto/README.md).

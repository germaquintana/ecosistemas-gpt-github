# 01 · Tu primer proyecto GPT + GitHub

## Resultado de este ejercicio
Crear un proyecto **privado**, definir un entregable pequeño, dividirlo en acciones y registrar al menos una entrega verificada.

1. Elige una necesidad real: por ejemplo, organizar fuentes para un informe sencillo.
2. Define **objetivo** (para qué), **producto** (qué entregarás), **criterio de aceptación** (cómo sabrás que está listo), **responsable** y **alcance**.
3. Crea un repositorio privado propio. Revisa quién tiene acceso antes de subir datos.
4. Copia y personaliza [la plantilla](../plantilla-proyecto/README.md). Adapta `AGENTS.md` antes de pedir tareas al asistente.
5. Define una issue o tarea, y una `next_action` verificable en el estado.
6. Trabaja con información ficticia hasta entender el ciclo. Si necesitas originales reales, guárdalos en su sistema autorizado.
7. Confirma el resultado, escribe un RUN breve y deja el siguiente paso.

**No confundas** documento redactado con documento aprobado, mensaje preparado con mensaje enviado, o proceso iniciado con proceso terminado.

## Verificación de aprendizaje
¿Otra persona podría abrir tu README, saber qué quieres conseguir, encontrar la próxima acción y comprobar la evidencia de la última entrega? Si no, simplifica y corrige antes de automatizar.
